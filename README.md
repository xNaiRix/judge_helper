## Как это связано

1. **Требования** зафиксированы в ТЗ; по ним составлен риск-ориентированный **план тестирования** (196 функциональных кейсов + NFR + UAT).
2. Тест-кейсы заведены в **TestY** (self-hosted TMS, развёрнут в `testy/` через Docker; импорт — скриптами из `tools/testy_import/`), исполнители и сроки назначены из `docs/распределение_задач.xlsx`. Задачи дублируются в таск-трекере (YouGile/Jira) по [руководству](docs/testy_руководство.md).
3. **Приложение** — реализация ТЗ (FastAPI + SQLAlchemy + SQLite): JWT-авторизация с подтверждением email и восстановлением пароля, соревнования с автоудалением через год, приглашения, участники с защитой от дублей ФИО, оценки 0..10 с офлайн-синхронизацией (LWW), результаты с banker's rounding, уведомления с настройками, аудит-лог, отчёты CSV/PNG/PDF, статистика по судьям, rate limiting.
4. **Автотесты** (pytest) покрывают приложение на 97% (порог ТЗ — 80%) и привязаны к группам тест-кейсов плана.
5. **CI/CD**: на каждый push/PR — ruff-линт, тесты (Python 3.11/3.12) с отчётами покрытия и junit, smoke-проверка; после успеха собирается Docker-образ, проходит smoke-тест в контейнере, сканируется Trivy (CRITICAL/HIGH → GitHub Security) и публикуется в GitHub Container Registry (ветка `main`, теги `v*`).

## Быстрый старт

```bash
# приложение + тесты
cd app
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m uvicorn judge_helper.asgi:app --reload --app-dir src   # веб-интерфейс: http://127.0.0.1:8000/
pytest --cov=judge_helper --cov-report=term-missing              # 179 тестов, Swagger: /docs

# приложение в Docker (сборка локально)
cd app && docker compose up --build   # http://127.0.0.1:8000/

# приложение из готового образа GHCR (после зелёного CI) — одна команда
# один раз: создайте .env в корне со строкой JUDGE_IMAGE=ghcr.io/<owner>/<repo>/judge-helper:latest
docker compose -f docker-compose.deploy.yml up -d   # миграции применяются автоматически

# TestY (TMS)
cd ../testy && docker compose up -d                               # http://localhost
```
