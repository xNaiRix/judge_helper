## DEF-01 (POM1-101) — Оценка «10,5» принимается API

| Поле | Значение |
| :-- | :-- |
| Кейс-источник | FIN-03 (план, раздел 7.6 «Старт, оценки, комментарии») |
| Окружение | Сборка 0.9.0, Windows 11, Chrome 130; API http://127.0.0.1:8000 |
| Предусловия | Соревнование в статусе «идёт», судья авторизован |
| Шаги | 1. `POST /competitions/{id}/scores` с телом `{"participant_id": 1, "value": 10.5}` |
| Ожидаемый результат | 422 Validation Error (граничное значение: допустимы только целые 0..10) |
| Фактический результат | 200 OK, оценка 10,5 сохранена и попадает в среднее |
| Severity / Priority | Critical / P0 |
| Вложения | Скриншот Swagger-запроса и ответа; запись из лога приложения |
| Комментарий | Граничное значение выше верхней границы пропущено серверной валидацией (Pydantic-схема без ограничения `le=10`) |
| Жизненный цикл | 12.11 Открыт (Дарья) → 13.11 В работе (Тимур) → 13.11 Исправлен → 14.11 Re-test: Pass, закрыт |

## DEF-03 (POM1-103) — UI показывает «Принять приглашение» после старта

| Поле | Значение |
| :-- | :-- |
| Кейс-источник | COMP-14 (план, раздел 7.3 «Соревнования и приглашения»; правило ТЗ 3.1) |
| Окружение | Сборка 0.9.0, веб-интерфейс, судья с необработанным приглашением |
| Предусловия | Приглашение отправлено до старта; соревнование запущено администратором |
| Шаги | 1. Войти судьёй. 2. Открыть страницу приглашения. 3. Нажать «Принять» |

| Вложения | Скриншот страницы; ответ API из Network-панели |
| Комментарий | Расхождение UI-контракта с API-контрактом (серый ящик: видно через консоль браузера). По ТЗ 3.1 после старта «принятие недоступно» |
| Жизненный цикл | 17.11 Открыт (Дарья) → 18.11 В работе (Тимур) → 19.11 Исправлен → 19.11 Re-test: Pass, закрыт |

| Вывод для команды | Перед заведением дефекта — минимум одна чистая попытка воспроизведения по шагам кейса (см. [docs/testy_руководство_тестировщика.md](testy_руководство_тестировщика.md), раздел 5) |
